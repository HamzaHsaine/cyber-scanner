# 🔥 Cyber Port Scanner

A Python-based port scanner built for learning cybersecurity and networking.

## 🚀 Features
- Multi-threaded scanning
- Service detection
- Domain to IP resolution
- Colored terminal output
- Scan report generation

## 🛠️ Technologies
- Python
- Socket
- Threading
- Colorama

## ▶️ Usage
```bash
python scanner.py

## 🛠️ Installation

```bash
git clone https://github.com/HamzaHsaine/cyber-scanner.git
cd cyber-scanner
pip install -r requirements.txt
python scanner.py
